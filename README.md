# Exploring-Bonds-Stocks-Portfolios
The purpose of this project is to explore the different types of bonds, stocks, and portfolios, and to provide a comprehensive analysis of their characteristics, advantages, and disadvantages

## Notes

- **Senior_Project_Formulas.Rmd**: This R Markdown file contains the main analysis including financial calculations (future value, present value, bond pricing), time series analysis (noise, random walks, Wiener processes), and portfolio optimization using stocks like TSLA, CVX, COST, PEP, and AMC.

- **Requirements**: To run the R code, you need R installed along with the following packages:
  - quantmod
  - TSA
  - tseries
  - PerformanceAnalytics
  - moments
  - boot

- **Installation**: Install required packages using `install.packages("package_name")` in R.

- **Usage**: Open the .Rmd file in RStudio and knit it to generate the HTML or Word document output.
